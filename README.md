# 🧠 NeuroTrack – Cognitive Performance System

NeuroTrack is a real-time cognitive monitoring system inspired by emerging neuro-tech platforms like Temple.

It simulates brain signal data and transforms it into actionable insights for performance, focus, and mental state optimization.

---

## 🚀 Features

- 🔐 User Session Login
- 📊 Real-time Brain Signal Visualization
- 📈 Session Timeline Tracking
- 🧠 AI-based Cognitive Coaching
- 🎯 Performance Score Calculation
- 📘 Insights System (Low / Medium / High Focus States)
- 🎛 Mode Selection (Work / Study / Athlete)

---

## 🧠 Concept

The goal is to simulate a system that:
- Tracks brain activity continuously
- Understands cognitive state
- Provides real-time guidance to improve performance

Inspired by the idea of:
> “A Fitbit for your brain”

---

## 🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI (Python)
- Visualization: Chart.js
